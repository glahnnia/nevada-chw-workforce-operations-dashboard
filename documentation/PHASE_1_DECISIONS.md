# Phase 1 — Definitions and Open Decisions

Created initial proposed data dictionary (`data/DATA_DICTIONARY_v1.md`) and KPI framework (`analysis/KPI_FRAMEWORK_v1.md`). These are design drafts; no synthetic dataset or dashboard has been produced yet.

**Recommended decisions for v1:** Use fictional Nevada-oriented CHW training cohorts, distinct learner and enrollment IDs, cohort-based training measures, and optional certification/employment follow-up with prominently displayed response coverage.

**To decide before data generation:** sample time period/cohort count; illustrative language and geographic distributions; whether to include workforce follow-up in the first implementation.

**Next build step:** create synthetic CSVs plus a reproducible validation script; do not import real student records.
